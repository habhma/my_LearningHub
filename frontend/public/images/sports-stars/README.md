# Sports Stars Images

## Instructions

Place images for each sports star in this folder with the following naming convention:

- `messi.jpg` - Lionel Messi
- `ronaldo.jpg` - Cristiano Ronaldo
- `serena.jpg` - Serena Williams
- `lebron.jpg` - LeBron James
- `kohli.jpg` - Virat Kohli
- `bolt.jpg` - Usain Bolt
- `simone.jpg` - Simone Biles
- `federer.jpg` - Roger Federer
- `neymar.jpg` - Neymar Jr
- `djokovic.jpg` - Novak Djokovic

## Image Requirements

- Format: JPG or PNG
- Recommended size: 400x400px (square)
- Maximum file size: 500KB each

## Where to Find Images

You can download images from:
1. Official athlete websites
2. Licensed stock photo sites
3. Creative Commons sources (with attribution)
4. Or use the original Wikipedia URLs and save the images locally
